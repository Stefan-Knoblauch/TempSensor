# TempSensor

Rail temperature sensor for the Transnet/PRASA network: a magnet-mounted, electrically floating rail-web unit in three tiers (cheap, mid-range, advanced).

## Contents
- `docs/research/rail-temperature-sensor-research.pdf`: design research (Markdown source alongside).
- `docs/design/design-methodology.md`: design methodology, system layering, requirements and verification plan (desk-based; no field testing yet).
- `docs/design/tier1-core-design.md`: Tier 1 core specification (Transnet-derived requirements, architecture, firmware, payload, energy budget, verification).
- `tools/build_pdfs.sh`: regenerates PDFs from Markdown (`tools/build_pdfs.sh docs/research/*.md`; needs pandoc and Chromium).
